# Sandbox — بيئة تنفيذ الأكواد المعزولة

هذا المجلد مخصص لصور Docker التي تُشغَّل فيها أكواد الطلاب **بأمان تام**.

## الضوابط المطبّقة في `pipeline/sandbox_runner.py`
- `--network none` : لا شبكة إطلاقًا.
- `--read-only` + `--tmpfs /tmp` : نظام ملفات للقراءة فقط.
- `--memory` و `--cpus` و `--pids-limit` : حدود موارد صارمة.
- العمل داخل مجلد مؤقت يُحذف بعد التشغيل.
- مهلة زمنية قابلة للضبط (`SANDBOX_TIMEOUT`).

## الصور المستخدمة
تُشتق من `pipeline/languages_data.py` (حقل `docker_image`) لكل لغة، مثل:
`python:3.12-slim` · `node:22-slim` · `gcc:14` · `golang:1.23` · `php:8.3-cli` …

## التوسعة (المرحلة 5)
- مختبرات CTF بصور مخصّصة لكل تحدٍّ.
- منافذ داخلية معزولة عبر شبكة خاصة بالـSandbox.
- أعلام (flags) تُتحقّق من قاعدة البيانات.
